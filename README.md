# COVID Dashboard

An interactive COVID-19 dashboard built using Python and Jupyter Notebook.

## Features
- COVID admissions analysis
- Death statistics visualisation
- Interactive charts
- Data processing using JSON datasets

## Technologies Used
- Python
- Pandas
- Plotly
- Jupyter Notebook

## Files
- `Final Dashboard.ipynb` → Main dashboard notebook
- `admissions.json` → Admissions dataset
- `deaths.json` → Death dataset
